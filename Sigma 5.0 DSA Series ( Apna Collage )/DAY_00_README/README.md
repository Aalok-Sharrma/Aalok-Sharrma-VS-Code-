    Following is rules of naming convention in java

      (1) For "Packages" --> all lowercase --> (ex : day9array.d919questions) 
      (2) For "Classes and Enums" --> PascalCase --> (ex : AalokSharrma)
      (3) For "Interface" --> PascalCase --> (ex : AalokSharrma)
      (4) For "Methods and Variables" --> lowerCamelCase --> (ex : studentAalokSharrma)
      (5) For "Constants" --> All UpperCase With UnderScore(_) --> (ex : AALOK_SHARRMA)
